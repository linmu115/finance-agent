# K4 预期差账本计算核心

2026-10-07，feat/fin-workpapers；按最新指令只做核心和单测，无新增入库。

入口：`service.workpaper_expectations.expectations_report(records, actuals=(), as_of=None)`。records 可使用已有研究记录的 analyst_forecast / currency-per-share 契约，或 `{value,unit,currency,source}`；包含主体身份、指标、期间、机构、ISO 日期和口径。actuals 为显式提供的原财报事实或 reported_actual，不接受研报 quoted_actual 冒充原财报实际。同一工具的 expectations 数据适配尚未注册，等待材料获准入库与原文验收。

账本按金额/每股/币种分表（如 ledger_CNY_money、ledger_CNY_per_share），避免同列混量纲；revisions、actual_vs_expected 同样分表，另有 excluded 和 observations。同机构的版本按原发布日期排序；同日同口径同值重复引用合并计算但保留全部来源，不同值保留冲突；不能回退到更早版本并称为最新值。实际匹配保留主体、年度、指标、币种、报表口径、每股/重述基础和维度，各预测情景独立保留。实际值无预测情景，不因此拒绝基础/乐观情景与同一个实际值的比较。

截止日含当日；晚于截止日、发布日期未知、非预测和机构/报告口径未知的记录单列，不进入当时的预期。无截止日表示使用提供的全部明确日期，不静默采用机器当前日期。实际值是显式的事后回测参照，其披露日期与时间身份单列，绝不声称截止日已经知道之后的实际结果。差额为实际减预测，差异率为差额 / abs(预测)；预测为零时保留金额差额、差异率缺项。机构最大/最小偏差按同指标同口径绝对金额排名，并列保留。

11 项测试通过：截止日边界、未知日期与非预测排除、最新版本选择、修正轨迹、金额和 EPS 分列与倍率、主体/期间/口径/币种/每股基础隔离、情景与分部、同日冲突、重复来源、实际冲突、零/负预测与并列机构、原记录来源追踪、输入不变、无截止日语义及非法日期。合成示例 A 机构预测 100 → 110、B 机构 125、实际 120，A 最新差额 +10、B -5，最大偏差 A、最小 B；EPS 1.78 → 实际 1.90 的差额为 0.12 元/股。

偏差与边界：用户本轮明确要求 K4 先只做核心与单测，伊利 2024 净利润/EPS 的补充研报和原文验收尚未执行。2025-07-16 国信报告不可冒充 2024-12-31 时点的预测，现有材料不足以完成该历史账本。K4 未调用模型，也无准备成本与分析成本的混记。
