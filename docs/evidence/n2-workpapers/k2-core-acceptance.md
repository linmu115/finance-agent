# K2 比较底稿计算核心

2026-10-07，feat/fin-workpapers；按最新指令只做计算核心与单测，不新增入库。

入口：`service.workpaper_comparison.comparison_report(subjects)`，每项主体期间给出 entity_id、company、period、period_start/end、scope、currency、metrics；metrics 使用现有 `{value,unit,currency,source}` 数值契约，余额明确 `_begin/_end`。metadata 的 `{value,source}` 用于可比性披露。此阶段不注册 comparison kind：资料读取适配与原文验收尚待补充材料，不能把合成输入冒充真实金融工具已完成。

输出统一 report：原金额、共同比利润表/资产负债关键项、平均余额杜邦、现金转化、营运天数、增速、可比性、数值发现。复用 analysis_report 单位换算和 financial_quality 现金/周转公式。每主体列固定币种，未隐含换汇；合并净利润与归母利润分别保留。杜邦不借用归母利润，不把期末余额当平均余额，也不擅自年化中报。缺期初值只影响有关比例，负/零分母明确缺项。

验证：7 项核心测试通过；其中独立合成样例核对 34 个数值。收入 1,200、合并净利 180、期初/末资产 900/1,100、权益 400/500（百万元）得到净利率 15%、资产周转 1.2、权益乘数 2.222…、ROE 40%；三因子乘积 40%，残差 Decimal 计算精度内为零。366 天期间 DSO 36.6、DIO 91.5、DPO 50.8333…，CFO/净利 120%。单位倍率、缺期初余额、币种和报告范围冲突、跨期窗口、亏损和零分母、证据保留及输入不变均覆盖。K1/K2/K3 共 30 项相关测试通过。

偏差与边界：这 34 个数值是计算核心的合成参照，不计入 spec 的至少 30 个原文数值抽查。伊利 2023/2024、美的/海尔 2024 的真实比较、调用参数适配、完整入库和费用记录均尚未实施；须先核对可复用的现有材料，再由主线确认新增材料。
