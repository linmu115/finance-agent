各类依据：

1. **指标**：标准标签与原格行列语义可唯一对应时才规范化；旧 ID 保留在 aliases，含原行/列坐标证据。NCI/Owners 必须有原文利润归属、综合收益归属或权益表块证据。余额/准备/净值/变动等不同计量列保留各自原 ID。
2. **准则与口径**：卡罗特 732 条 IFRS 后缀改 HKFRS，仍保留第 52 页编制基础等原文证据。茅台 27 条 `unspecified_unknown → consolidated_unknown` 来自既有主要会计数据来源语义规则；该 22 页子集缺少完整准则声明，未猜 CAS。
3. **期间**：茅台 15 条余额转为原表头日期时点，其中 6 条期初余额从 2024-FY 转为 2023-12-31 并改 year。此类是旧开发样本补应用既有规则，F2.0.1 没改期间算法。伊利、海尔、卡罗特 period/year 零变化。
4. **维度值**：海尔 2 条沿用原资产章节增加 balance_side。茅台 189 条为原文有名称的构成分项和资产方向；相对旧 v3 多 13 条来自保留原指标后恢复了同指标“明细—合计”关系，全部有非空原行名与合计行证据。没有空名称切分维度。
5. **维度角色**：仅同一指标/期间单值、原行/列与 financial_item 的意义一致时为 descriptive；重述比较列为 comparison_version。共享此次列语义判定，不会把存货三种计量因数值恰好相同而视为描述性维度。
6. **审计元数据**：只随实际语义变更保留旧 ID、规则证据、来源修订与历史。未改动的待核事实不批量加标记。全部差异包括这些元数据，未隐去。

从旧 v3 结果升级时，变化事实数为卡罗特 16、伊利 41、海尔 22、茅台 13；其中部分恢复原 ID，部分补足明确表块/列语义后的规范 ID。升级与直接修复的 metric、scope、period、year、dimensions、dimension_roles 完全相同；版本审计路径不同按实保留。
