## 截止日、修正和缺陷

- **国信 2025-07-16**：本年度查询得到 24 条截止日后记录，全部进入排除表，未进入账本、最新预测、修正或参照差额。它们是研报引用实际值，也未替代年报事实。截止日当天纳入、未来预测排除、未知日期排除另有核心单测。
- **光大机构名**：“光大证券”与“光大证券股份有限公司”归为同一机构，保留原展示名。5 月→11 月 EPS 为 2.05→1.89，原数变化 −0.16；来源维度、每股分母未齐，不能叫同口径下调。净利润 13,063 百万元→归母 12,019 百万元只列前后记录，差额留空，归属不确定不混算。5 月没有核心收入预测，不制造前值。
- **华泰**：p3 一条被标为“净利润”的 8,985 百万元，原坐标实际是“经营活动现金”，明确排除；不靠它判断预测净利。另 6 条带未对齐 financial_item 维度的候选保留待核；p2 两条可比公司平均/中位 EPS 排除。p1 三项核心值不受影响。未修写源数据，也未声称已修复整张现金流表。
- **光大 11 月 p2**：存在已解析但没有当前结构化记录的表。核心 p1 三项可验收；无法确认 p2 是否有进一步口径、假设或跨页矛盾。产品 coverage 给出未结构化表的页范围，不把它描述成整页没有数据。
- **额外期间缺陷**：伊利三季报利润表 4 条记录被标为 2024-FY（收入、归母净利、基本及稀释 EPS）。依据报告标题将其单列，不用作全年实际值，也不在本任务重写为 9M。
- **年报**：三大表可用，全文状态仍 normalizing；披露日字段未知。实际金额来自年报 p91–92，未拿晚于截止日的研报“实际”代替。未覆盖的全文项目不推断完整。
