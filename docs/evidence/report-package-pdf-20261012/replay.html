结论

回答 1 · 2026-10-11T16:00:30.860Z

【推论/分析】结论： 2024年伊利经营现金流增加，最直接的披露原因是为2025年春节备货时，经销商预收货款增加 。【推论/分析】现金流桥显示，营运资本贡献较上年明显转强，抵消了净利润下降的拖累；但春节备货和预收款有时点性，不能据单年改善判断经营现金流已形成可持续的新水平 。

现金流同比桥

【推论/分析】

【事实/数据】按间接法拆解，2024年合并经营现金流净额为 21,739.7404 CNY 百万元，2023年为 18,290.3577 CNY 百万元，同比增加 3,449.3827 CNY 百万元（均为百万元）。【推论/分析】图中营运资本贡献的上升是主要正向桥接项；其余分项与净额共同构成同比变化。

原文依据与解释

【推论/分析】年报在解释现金流变化时写道：“主要因2025年春节备货，预收经销商货款增加使得本期经营活动现金流量净额增加所致。” 【事实/数据】（《伊利股份2024年年度报告》，document_id：d84573bf6b584e7e874faa4c6adf454a，第19页）年报还披露，“合同负债增加原因：本期预收经销商的货款增加所致。” 【推论/分析】（同报告，第26页）

【推论/分析】这与间接法桥接方向相符：营运资本项目对CFO的合计贡献较上年改善；其中经营性应收项目的调整改善、经营性应付项目的调整改善，部分被存货调整的同比走弱抵消。现金流调节表的分项见报告第218页。这些是现金流桥接项目，不等于每项变化的独立因果解释；期末合同负债余额增加也不能直接等同于当年CFO增量。

【事实/数据】另一方面，2024年归母净利润为 8,452.8600 CNY 百万元，2023年为 10,428.5405 CNY 百万元；利润下降确实构成现金流改善的反向背景。【推论/分析】需要区分的是，现金流量表间接法从合并净利润 出发，而归母净利润是股东归属口径，不应把两者混作同一个桥接起点。

能否持续

【推论/分析】判断：部分改善可能延续，春节备货带来的这部分增量存在回落或反转风险。 【推论/分析】公司明确将本次CFO增加与2025年春节备货、经销商预收款联系起来；库存相关披露也称液体乳期末库存较大与春节备货有关（同报告，第20页）。因此，预收款及备货节奏是有原文支持的时点性解释，但年报未给出该因素对CFO增量的独立金额，无法精确估算次年反转幅度。

【推论/分析】适用范围 / 风险： 以上判断基于2024年年报与2023年比较期的单年对比。【推论/分析】要确认持续性，还需观察节后合同负债、库存和后续期间CFO是否回落，以及销售回款和营运资本是否继续支持现金流；目前证据不足以判断改善会持续多久。
