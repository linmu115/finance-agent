## 结论

**利润与经营现金流方向背离：利润明显下滑，经营现金流反而增长。**现金回收表现强于账面利润，但不能据此认定盈利质量全面改善：扣非利润降幅更大，且经营现金流受到减值等非现金调整、营运资本变动的显著影响。另一个值得关注的点是，**经营现金流增加的同时，现金及现金等价物大幅减少**，主要与投资现金净流出扩大有关。

| 2024年指标 | 披露或计算结果 |
|---|---:|
| 营业收入 | 1,153.93亿元，同比-8.24% |
| 归母净利润 | 84.53亿元，同比-18.94% |
| 扣非归母净利润 | 60.11亿元，同比-40.04% |
| 经营活动现金流净额（CFO） | 217.40亿元，同比+18.86% |
| CFO / 合并净利润 | 2.57倍（计算） |
| CFO / 营业收入 | 18.84%；2023年为14.54%（计算） |

## 值得警惕的地方

1. **扣非利润下滑幅度显著大于归母净利润。**2024年归母净利润与扣非归母净利润相差约24.42亿元（计算）。年报列示非流动性资产处置损益约25.64亿元，是非经常性损益中的大额项目。也就是说，**报告净利润没有充分反映经常性盈利的疲弱程度**；处置损益本身不宜当作可持续利润来源。[年报第7—8页]

2. **CFO增长有明显的非现金调整和营运资本贡献，不等于利润同步转强。**现金流量表补充资料显示，资产减值准备调整为约46.76亿元，上年约15.26亿元；经营性应收项目减少带来约18.25亿元现金贡献，经营性应付项目增加带来约26.11亿元现金贡献。**这些项目能抬高当年CFO，但不代表利润趋势反转或未来每年都能重复。**[年报第217—218页]

3. **单季背离尤其明显。**2024年第四季度归母净亏损约24.16亿元、扣非归母净亏损约24.98亿元，但当季经营现金流净额约78.70亿元。利润与现金流在该季度显著背离，提示应进一步关注非现金损益及营运资本季节性变化，不能只看全年CFO判断经营盈利趋势。[年报第8页]

4. **现金余额明显下降，需与经营现金流分开看。**2024年投资活动现金净流出约327.09亿元，较上年约160.44亿元扩大；筹资活动现金净流出约72.78亿元。年末现金及现金等价物约245.47亿元，较年初减少约182.66亿元。年报中投资支付现金约342.54亿元，上年约149.82亿元；因此，现金减少更直接地反映投资现金支出增加，而非CFO下降。[年报第95页]

**综合判断：**经营现金流表现强于利润，短期现金回收并不差；但核心警示是**利润、尤其扣非利润走弱，且CFO受到非现金调整与营运资本变动支撑**。因此不能把现金流增长直接解读为盈利质量或经常性盈利改善。分析范围为2024年报披露及据此计算；上述因素说明现金流与利润为何背离，但不单独证明具体经营原因或未来走势。
