# N4 模型采用率研发预检

代码固定 7524cca，题目和资料清单固定于 manifest.json；6 题各 financial/prepared 一次，独立新会话、逐题交错顺序。CPA gpt-6-luna，产品原生路由 low、财务分析 high，以实际请求日志核实。不增加工具名、任务提示中的工具引导或标签/绑定要求，不运行正式盲评。

只读从主库按 3 个明确文档 ID 复制原文、结构记录及目录，不复制历史答案或模型，不复制其他文档。每个会话使用相同 seed 的独立副本；不访问主线 HTTP。沿用 N3 的进程内 RunManager、stdio FinanceService 和无监听桥接适配；未修改产品源码、原生 Pi 循环、工具 schema 或系统指导。

题面只加两组相同的资料边界：已有材料分析，不联网、不重新入库/清洗。原报告未完整入库是当前资料状态，保留缺失。启动副本时产品 Store 会将 normalizing 状态转为 failed，已记录；事实及原文保持不变。

记录工具与 kind、原始答案模板和绑定后的正文、标签、错误/遗漏、实际请求数及输入/缓存/输出/未知用量。绑定率按最终答案中量化断言计数，排除年份、页码、编号、URL；原始模板占位符算绑定，整表展开按实际数值格计数，不能只按占位符数量除以渲染后数字数量。自动统计后人工检查边界。所有请求计为研发预检，CPA 费用缺价格时保持未知。

只提出改进建议，完成后交一页采用漏斗与问题清单，附逐题审计证据。产品问题不在本次修复。
