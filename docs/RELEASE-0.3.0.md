# Finance Agent v0.3.0

本版在完整财报/研报入库与 Pi 原生执行的基础上，改进数据复用、数值交付、证据核验和公式展示，并增加项目附件看板。新版本保留 v0.2.0 标签、论文及历史实验。

## 主要变化

- 查询返回必要数值及来源身份，减少重复审计和规范化历史回传；金融模型支持直接绑定财务事实/研报记录，支持保存版本、更新与情景比较。
- 分析工具提供统一数值报告：一次换算用于 CSV、图形和报告；继续支持自由 Python，提供中文字体和制图主题。该路径不能自动纠正任意自写脚本或错误来源语义。
- 保留疑点和候选证据，按其对当前计算的影响复核；程序进度用于恢复，取消不必要的逐表 LLM 读回/确认。
- 修复附件类型/下载、正文观点入库的主体契约、未知用量记账，并统一 Markdown/GFM 与 KaTeX 公式展示。
- 移除“数据集与测试”导航，增加“附件看板”：项目内逐条查看登记资料及入库数量；确认删除后清理该资料当前和历史入库数据、全文检索与处理快照/产物。保留历史会话与已有备份，依赖来源的保存模型显示失效。
- 更新技术论文正文和 PDF，纳入优化方法、正式分析比较、失败与限制，而不只追加试验日志。

## 分析对照结果

卡罗特 55 页中报和 47 页研报准备一次，入库成本单列。主比较为同模型、同准备数据的通用 Pi 与金融组，各三题、两次重复；辅助原文组三题一次，共 15 项。正式请求登记为 CPA GPT-6 Luna，代理背后的实际模型身份及费率未独立核实。

| 已知指标 | 通用 Pi，6 项 | 金融组，6 项 |
|---|---:|---:|
| 累计输入 token | 5,123,875 | 2,674,311 |
| 输出 token | 53,264 | 40,874 |
| 未缓存输入 | 369,443 | 423,047 |
| 模型调用 | 83，含 1 笔用量未知 | 56 |
| 沙箱执行失败 | 12 | 2 |

输入减少 47.81%、输出减少 23.26%，但未缓存输入增加 14.51%。研报估值题的输入减少 71.89%，现金流题有局部解释收益。156 个登记产物均可下载，155 项脚本产物内容经重放一致；重放一致不意味着原结果正确。没有证明整体金融质量、实际费用或模型复用稳定优于基线。

## 已知问题

本轮仍出现自主导出 CSV 的金额/百分比单位失配、部分图表标题或色标重叠、共有报告接口拒绝合理单位写法及 Markdown 表格格式缺陷。金融模型版本更新接口没有在两次真实更新中被使用，模型仍重写脚本。正式分析一项曾因 Windows 审计文件 EBUSY 导致宿主中断，原会话恢复后完成，产生一笔未知用量。此发布保留这些原始结果，不宣称上述问题已修复。

## 安装与升级

下载 `finance-agent-0.3.0-windows-x64.zip` 和 `SHA256SUMS.txt`，核对哈希后完整解压，双击 `install.cmd`。便携包自带 Node 24.7.0、Python 3.12.11 和锁定生产依赖；Docker 引擎和计算镜像需另外准备。服务仍只使用 3001，不自动启动 Docker/WSL。

升级前停止旧实例并备份实际数据目录，再让新版使用该数据目录。不要覆盖正在运行的安装目录或把空包的配置复制到旧数据中。详细启动、API 配置、入库与看板操作见 [使用指南](START_AND_USE.md)。

代码与本次发布检查见 `docs/evidence/v0.3.0/regression-summary.json`；ZIP 逐文件校验及独立中文/空格路径下的离线部署验证附在 Release。离线验证不调用模型、不启动 Docker、不另开应用端口，不等同于对全新系统进行 HTTP 安装/停止及真实模型验收。
