# Finance Agent 0.1 发布说明

这是首次便携部署发布，内部版本号为 0.1.0，Git 标签为 v0.1。

## 本版包含

- 项目下嵌会话、附件流向通高右栏、原始资料核验。
- 输入区逐次数据库操作授权、DSH 风格划选引用与注释。
- 财报看板、联网来源归档、研究成果与版本记录。
- 项目约定、专业技能加载、Python/CSV 财务建模。
- Windows x64 便携运行环境与安装、启动、停止、环境检查入口。
- 5 份完整年报与实际分析问题。

## 发布边界

- 程序与依赖内置，API 密钥、真实用户数据、沙箱私钥和机器运行状态不随包分发。
- 高级任意代码分析的 Docker 引擎/镜像为可选外部组件；本包不会自动启动或安装 Docker/WSL。
- 单用户、本机使用，不提供公网登录或多租户隔离能力。
- 本包未商业签名，使用发布页 SHA-256 校验下载文件。
- 文档抽取、口径识别和金融分析仍需原文核验。历史 benchmark 编号和成绩保留为历史证据，不因发布安装包而宣称全部通过。

## 验收记录

发布构建前的类型检查、前后端构建、154 项 Node 测试与 313 项 Python 测试通过。它们不能替代下面的新目录部署验收。

最终构建及新目录部署检查结果记录在发布资产 `deployment-verification.json`，其验证目标包括：

- 全新中文及空格路径，独立数据目录，使用内置 Node/Python。
- 安装环境检查、本地 API/前端启动、重复启动复用、端口冲突保护。
- 上传解析与来源查看、项目和会话持久化、停止后重启。
- 停止仅作用于本安装进程及其文档服务，既有 3001 开发服务保持不变。
- 源码排除规则、凭据扫描、ZIP CRC 与逐文件 SHA-256。

JSON 中实际通过的项目是本次验收结论；不将验证目标文字本身视为通过证据。
