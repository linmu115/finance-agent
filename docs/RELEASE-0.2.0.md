# Finance Agent 0.2.0 发布说明

发布日期：2026-10-05。Git 标签：`v0.2.0`。平台：Windows x64。上一版 `v0.1` 保留。

本版把财报、研报和已保存模型汇集到按研究对象浏览的资产看板，并改进长任务恢复、脚本清洗、推理路由及费用透明度。

## 本版变化

- **统一资产看板：** 合并原财报看板和研究成果导航，包含总览、财务与经营、机构预期、观点与证据、模型与成果；支持对象筛选、报告截止日、同口径最新预测、原文和带引用会话草稿。
- **研报入库：** 来源机构、作者、日期、多公司/行业对象、预测版本与正文观点；表格和正文分别记录覆盖。复用财报的解析、脚本沙箱和来源校验，不重复处理同一张表，不把研报预测写成正式披露。
- **脚本清洗：** 模型制定映射规则，程序从原始格取数；脚本可复用、逐表提交、检查点可继续。包含列级维度别名、冲突和同格多值防漏修复。
- **原生 Pi 接入：** 移除工具总次数截断和宿主自定义摘要输出覆盖，保留原生压缩、重试、途中追加、排队和持久会话；安全授权与单次沙箱资源边界保留。
- **推理与费用：** 普通清洗最低 low、疑点允许 high，分析建模使用更充分推理；固定提示前缀在前；任务下方区分缓存输入、普通输入、输出、思考与各阶段费用。
- **专业复核：** 金融技能增加利润桥、财务费用位置、EBIT 来源、终值外推和资产桥假设检查。无需 Excel 安装。
- **部署与文档：** 默认一个 3001 服务，统一 `data/active/`，版本从项目配置读取；新增启动与使用 README、升级说明和 15 页技术论文。

## 下载与启动

下载 `finance-agent-0.2.0-windows-x64.zip`，完整解压后双击 `install.cmd`；日常用 `start-finance.cmd`，停止用 `stop-finance.cmd`。页面为 http://127.0.0.1:3001/ 。详细操作、Docker 准备、实际分析题和故障排查见 [启动与使用 README](START_AND_USE.md)。

便携包内置 Node 24.7.0、Python 3.12.11 及生产依赖。API 密钥、私人资料、真实会话库、全局 Pi 配置和 Docker/WSL 状态不随包分发。Docker 引擎和 `finance-analysis:0.1` 镜像需要另行准备；镜像标签和应用版本独立。

## 验证范围

- 发布代码：167/167 Node、405/405 Python 服务测试；类型检查与构建通过。
- 真实模型验收：57 页中报、38 页公司研报；612 条披露、998 条研报数值、78 条观点、3 份模型。49/49 原文金额锚点、78/78 观点原句定位、修正后 75/75 模型检查通过。
- 真实数据页面：1440 和 390 宽度，导航、筛选、截止日、来源、草稿、图表、模型和 CSV 下载通过。
- 15 页论文：全部页面渲染检查；字体、页码、图表、段落与表格无越界，未发现替换字符。
- 发布包：源码允许列表与凭据扫描、ZIP 成员/CRC/逐文件 SHA-256；解压后内置环境和 stdio MCP 检查的实际结果见发布附件 `deployment-verification.json`，不可把验证目标本身当成通过。

为了保持本机只有 3001，本次包验收采用 stdio，不另开 HTTP 测试实例，不额外调用付费模型。新 ZIP 的 HTTP 冷启动、安装快捷方式和停止流程没有在此次离线包验证中重跑；该边界在验证 JSON 中明确列出。之前真实会话及看板检查与新 ZIP 的离线验证是两类证据。

## 质量及升级边界

财报仍有 6 张复杂表或叙述、研报 99 条记录待核验。流程完成、引用可定位、模型可复算不等于全量金融语义正确。技术论文详细说明样本量、修复反馈和估算费用的局限。

v0.1 常用 `data/`，本版默认 `data/active/`。先停止原实例、备份实际数据目录，再迁移；跨电脑或 Windows 用户重新填写 DPAPI 密钥。安装包为空数据状态，不含开发机已有的三个验收会话。

工作区上一次清理旧产物及停止服务曾被执行环境审批拒绝。本次发布排除了这些旧运行目录，并包含新增防漏校验源码；打包和推送不会自动替换已运行的开发进程。升级必须按指南先停止旧实例后再启动新版，不能仅凭工作区版本号判断当前进程已更新。
