# Finance Agent v0.4.0

本版将 F2.1 冻结构建（`7e702ff`）的产品能力整理为 Windows x64 可运行包。发布仅更新版本、打包范围与说明，分析和入库行为保持该评测版本。默认服务端口为 3001。

## 版本范围

- v3 底稿流水线：金融配置下先运行财报分析底稿，汇总经营指标、现金桥、期间比较、异常信号、业绩归因、口径变化和预期差，并连接原文来源。完整表可按句柄补读。
- 交付一致性：数值表与回答绑定、情景版本、局部修复与降级交付，支持报告和工作簿；事实、推论与观点分层。传输重试保留尝试及未知用量，附件内容通过流式下载交付。
- F2.1 修复：金融底稿的口径变化标记纠偏；瀑布图连续性诊断；正文、Markdown、CSV、Excel 的方向检查。后两项作用于共享增强交付层，原版通用智能体配置不启用。
- 三组评测配置保留原版通用智能体、同数据通用组和金融组，工具数分别为 10 / 13 / 32。产品默认行为不变。

## 正式评测结论

预注册的两项总体 E4 优势均未证实。金融层在开发核心的业绩解释、异常分析，以及封存测试集的特殊损益与会计口径分析上，带来了两遍评审均可复现的深度提升；封存测试集的 R3、R5 则未保持两遍同向。新增分析内容也带来了材料范围、单位与币种标签、可比口径语义等交付错误，局部深度优势尚未转化为完整交付优势。下一轮应针对这三类问题改进已有流程，而不是继续增加工具。

正式评测共 162 个题位，完成 161 个；两项主对比的开发核心和封存测试集 E4 均为未证实。金融组开发核心已知输入较原版组高 115.62%、较同数据通用组低 32.62%，封存测试集较原版组高 32.94%；不作无条件费用节省结论。三类子集实质缺陷有无一致率为 96.30%–98.15%，Cohen's κ 为 0.9207–0.9619。

证据：源码仓库的 `benchmark/blind-eval/F21_FORMAL_REPORT.md`、`data/evaluation/blind-eval-F21-formal-20261009/formal-results.json`；参赛技术报告第 7 章。数据目录、评测私有原文和会话不随可运行包发布。

## 已知问题与后续规划

以下直接摘自技术报告第 9 章规划，均为后续工作，未作为本版已修复能力：

> 材料范围：将题面允许与排除的期间、材料范围传到预计算、底稿选择和附件生成。
>
> 单位与币种标签：数值与单位、币种、每股口径共同传递，换算后同步生成正文、图表、CSV 和模型包标签。
>
> 可比口径语义：比较前明确利润归属、指标范围和调节项目；无法对齐时单列参考而非直接归因。
>
> 按请求测量系统说明、底稿、工具结果、历史消息与重试的成本，再使用 Pi 原生上下文变换，把已消费的大块结果替换为含关键数值、来源与未决事项的摘要，附可重新读取句柄；完整资料继续保存。

报告包的独立复算完整性、完整表语义下的指标契约，以及长任务批次边界接收指令也保留为后续事项。正式批次中 12 个原生模型复算包缺少 `finance_model.delivery_text`；本版不掩盖或宣称修复该问题。

## 安装与数据边界

完整解压 `finance-agent-0.4.0-windows-x64.zip`，核对 `SHA256SUMS.txt` 后运行 `install.cmd`。包内自带 Node、Python 与生产依赖，不要求系统安装同类运行时；首次使用在界面配置自己的模型接口。Docker 引擎与分析镜像需另行准备，安装程序不自动拉起 Docker/WSL。

只随包提供明确允许的源码、安装说明、第三方许可及用于解析验证的历史公开 PDF 小样。没有真实数据库、会话、密钥、评测私有目录、封存公司材料或开发缓存。完整财报由使用者自行上传。

升级前停止旧实例、备份实际数据目录；不要覆盖正在运行的目录或用空配置替换原配置。详细操作见 [启动与使用](START_AND_USE.md)。本次包的校验与敏感扫描结果随本地交接文件提供。
