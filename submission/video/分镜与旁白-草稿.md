# 初赛介绍视频 · 分镜与旁白（草稿）

**规格**
- MP4，1920×1080，30fps，时长 4:00–4:40（上限 5 分钟），文件不超过 500MB；
- 中文旁白：edge-tts（zh-CN 女声或男声，语速 +5% 左右）；
- 中文字幕：从旁白稿生成 SRT 后烧录。

**制作方式**
- 标题和信息页用 HTML 幻灯片（1920×1080），由 Playwright 截帧，或按页录制；
- 产品演示用 Playwright 录屏，录真实工作台，只浏览已有项目，不发起新的模型调用；
- ffmpeg 负责合成：画面、旁白、字幕、轻背景音（可选）。

**约束**
- 录屏必须等 v3 正式评测结束、3001 空闲之后再做；
- 演示数据只用开发集公司，**不出现 held-out（白云机场、青岛啤酒）**；
- 画面中不出现 API Key、本机用户名等隐私信息。
