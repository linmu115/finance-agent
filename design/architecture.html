LangExtract 是 process_documents 的内部实现。它需要的模型调用通过本次运行的私有桥接回所属 Pi ModelRuntime，统一使用配置、调用记录、预算和取消信号。固定财务公式由计算工具执行；无需为每项能力再建一个 Agent。

2. 一条带附件消息如何执行

1
添加附件
只保存原文件并登记 document_id；此时不调用模型、不写入财务事实。
2
点击发送
当前 Pi Agent 收到用户任务和附件 ID。需要标准化财务数据时调用 process_documents；只阅读研究资料时可先用 prepare_document_sources 建立索引。
3
建立原文索引
PDF 独立解析进程提取逐页文字、表格和坐标；保存原文件、FTS 关键词索引与 YAML 目录。
4
模型理解并清洗
LangExtract 通过 Pi 调用 DeepSeek，结合表头、上下文解释指标、期间、单位、币种、口径、重述及分部。程序按原单元格验证数值和执行十进制换算；同一会话随后归并指标目录，并结合原文审校各事实的期间。
5
分批入库并更新看板
处理全部可提取的财务主表和附注表。每批提交后可查询，保留来源、原值、语义映射及版本。
6
继续同一次用户任务
同一 Pi Agent 接着取证、查表、运行财务模型或调用容器制图，保存研究成果后回复结论与引用。切换会话不打断处理。

3. 一条研究任务：证据 → 模型 → 备忘录

证据用户附件 / 联网原文
原文定位、披露期间与口径
模型可编辑假设 → 计算与情景
来源引用及固定版本
成果图表、产业链、备忘录
结论、风险与反证条件
同一次 Pi 工具循环继续执行，中间成果和最终版本均保存在项目内
1
取得可定位的原文。
搜索摘要只用于找链接；读取后保存原文快照。任务有研究截止日时传入检索与读取工具，发布日期未定则保留未定状态，不凭网址猜日期。
2
明确事实、推导和研究假设。
模型参数按路径保存 input_basis 和 source_refs。情景可把所选版本的完整输入直接传给 DCF，避免手抄；金额与股数倍率、期间、价值时点均明确保存。
3
保存可复核的研究成果。
同一 Agent 保存产业链、投资备忘录或逐处纠错，附真实来源、依赖版本和资料缺项，再返回结论与下载入口。
4
修改假设，定点更新下游。
“研究成果”可直接改参数并重算新版本。旧版本保留，下游显示“资料已有变化”；Agent 读取变化后更新相关 DCF 和备忘录，不自动改写旧结论。

这是当前工具支持的路径。是否一次完成、数值和判断是否正确，仍须查看具体任务记录与独立核验。

联网查询、来源快照、模型与报告版本保存在 data/research/<project>/。保存原始文件字节或明确标识的提取正文，记录实际读取的来源和成果版本。模型保留输入、依据、公式与结果表，可按指定版本导出 JSON / CSV。引用位置或引文存在的校验，不等于参数语义和财务数值已通过独立验证。

6. 模型工具与执行边界

工具职责
prepare_document_sources只建立本项目文档的原文页、表格与导航索引；供按需阅读。
process_documents在当前 Pi 运行内读取、清洗并写入本项目；支持重新清洗。
get_data_catalog / get_document_index发现真实数据位置、字段、期间、处理状态与 YAML 导航。
query_financial_data / get_normalization_details动态指标与维度筛选；查看字段映射和数据来源。
list_documents / get_document查看当前项目资料。
search_evidence / get_source_page / get_source_table关键词检索，读取原页与原表。
get_financial_metrics / calculate_financial_metrics常用指标访问与精确计算。
run_analysis / get_analysis_status / get_artifact在独立科学计算容器执行分析与绘图，取回产物。
search_web / fetch_research_source
list_research_sources / read_research_source		搜索、读取、归档公开原文，按需读取旧快照；保存日期、原网址和来源标识。
get_research_model_schema / run_financial_model按输入规范计算并保存盈利质量、制造业情景、DCF与可比估值。DCF可引用已保存情景版本直接导入。
get_research_report_schema / save_research_report
list_research_artifacts / read_research_artifact		保存、读取产业链、备忘录和纠错，发现版本与依赖变化。

模型使用当前运行开放的业务工具。项目由宿主绑定；宿主负责附件登记、配置和持久化。自由分析容器预装 NumPy、pandas、SciPy、Matplotlib、Seaborn、statsmodels、scikit-learn、openpyxl 和中文字体，输入只读、输出限于本任务、默认断网，使用导出的数据副本。
