# SDK 行名空白匹配与表编号诊断

用户本轮已授权：两项小修复分别准备提交，不合并、不部署。正式入库仅通过已有会话的原生 steer 定向修复；调用计入正式资料准备。开发验收使用复制数据，零模型调用。

确认的问题：伊利 t254–t257 的生成脚本把表 ID 减 1；原文行名内部换行又使 metrics 精确匹配失败。SDK 必须保留原表编号与原文，只在匹配时忽略空白字符。已有精确匹配保持优先，非空白差异不作模糊匹配。

第一项：metrics 键与原始行名仅统一空白字符。若仅空白差异对应多个不同映射且没有精确命中，明确报告歧义，不任意选取。原始标签、坐标、单位和数值不变。

第二项：仅在缺失指标的错误上，比较所给行名与当前表及编号相邻表的匹配。相邻表明显更匹配时，补充原表编号、候选编号及匹配行证据；不更换目标表、不自动提交，不把疑似偏移当作确定结论。

验收：SDK 单测覆盖 Unicode 空白、换行、标点与文字差异、精确匹配优先，以及正负偏移、无偏移、共享行名和双侧候选。复制伊利与海尔已提交批次，旧版与新版 SDK 重建相同映射并比较输出、物化事实及问题；复制库事实和历史记录保持不变。真实失败映射的数据以静态字典提取后重放，不在宿主执行生成的 Python 代码。
