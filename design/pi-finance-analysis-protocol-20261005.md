## 三组与可比条件

| 组别 | 执行配置 | 分析开始时可用材料 |
| --- | --- | --- |
| A 通用 Pi | `generic`；原文读取、检索、Python | 相同 PDF 的原文页与原始表，无专业清洗数据 |
| B 通用 Pi加整理数据 | `prepared`；同一通用提示与 Python，加只读记录查询 | A 的原文，加与 C 相同版本的财务事实、研报数值和观点 |
| C 金融工具 | `financial`；现有金融工具和技能 | 与 B 相同的原文与整理数据，可直接绑定记录、复用模型、比较版本及用金融制图助手 |

三组仍由 Pi 原生循环、压缩与恢复执行；不加模型确认关卡。使用相同模型、提供商、可用推理级别、运行环境与问题。字体和完整脚本导出属于基础交付能力，三组共享。B 不加载金融技能、模型计算器、金融图表助手或其他组已保存的模型。`prepared` 仅用于实验，不改变普通会话的完整入库行为。

## 数据准备和费用

1. 财报与研报完整入库作为独立任务完成，保存原文摘要、资料版本、入库用量和待核验项；不把待核验信息删掉以获得干净样本。
2. B/C 使用相同准备结果。实验脚本经项目接口各自提供材料；如需跨项目复制，必须按用户逐次授权执行，不能直接绕过主库权限。没有复制授权时，可在同一准备项目使用互相独立的新会话，冻结期间的数据版本，B 的工具仍不得访问金融成果。
3. 三组分析均从独立新会话开始，问题中指定已有文档，不再次以“新附件”触发默认入库。各题不能继承其他组的答案。多轮复用另做连续会话实验，不能与首次分析混为一表。
4. **纯分析费**从发出问题开始计算全部请求，包括路由、压缩、失败和修复；**入库费**独立列示。另列“准备一次＋N次分析”总成本，明确 N 与资料准备状态。
5. 旧试跑金融组包含入库，不能与通用组直接问答金额作纯分析成本比；日志不能精确拆分的部分不主观估算扣除。

## 问题与评分

沿用同一 57 页瑞和中报、38 页国信伊利研报作开发回归；这不是未见样本。三组问题在发送前冻结，评分参考不放进工作项目或工具输入。

- 财务分析：期间/主体/单位和关键值、利润口径、利润至经营现金流调节，重点检查融资与经营活动分类和未解释差额。
- 研报分析：机构、署期、实际与预测身份、主要观点和风险的来源支持。提取失败不能当“无观点”。
- 建模及更新：初始估值与后续局部参数变更；评分包含全部变化参数、估值差异、FCFF 调节、目标值是否在敏感性范围内、终值用途、图表与计算数据一致性。
- 交付：图表中文、单位、坐标/色标、实际/预测表达；图片、CSV/Markdown与完整 Python 脚本均可下载复算。

记录完成率、样本正确率（给出分母）、金融解释错误、干预、耗时、输入/输出/思考、加权缓存命中及未知用量。不能用缓存命中率或程序测试通过证明金融优势。B−A 主要观察整理数据的贡献；C−B 观察金融工具组合的增量，不能仅凭一次开发样本宣称统计显著。
