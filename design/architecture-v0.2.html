02 / 数据处理、数据库与工具

先解析原件，再让模型查证据

PDF使用 PyMuPDF 提取每页文本及可识别表格；原生文字很少的页面渲染后交给 RapidOCR。Excel直接读取工作表、行列、公式及已有缓存值；CSV/TSV按表格解析。缺失公式缓存不当作零。原文页、原表单元格、页码与来源定位一起保存。

保守生成财务事实

仅对已识别指标、明确年份及可识别单位生成年度事实，保留原值、单位、规范值、期间、币种、合并/母公司口径与来源。当前支持收入、归母利润、经营现金流、资产、净资产等常见财务指标；不会把任意表格自动变成完整财务数据库。未识别字段仍留在原文和原表，可用检索或查表工具读取。事实冲突和OCR质量问题会返回提示，当前前端提供原文核查，不提供字段编辑工作流。

文本检索与数值查询分开

文本由中文重叠二元词及英文词项进入 SQLite FTS5；已实现可选Embedding API及本地向量缓存，索引后台运行，未配置或失败时明确回退关键词检索。精确数值通过事实表查询，计算由Decimal工具执行。外部Embedding服务尚未进行真实接入验收，现有模型成绩不称为向量检索成绩。

实际SQLite表保存内容
projects / documents项目、原始文件名、SHA256、解析版本、公司/年份、页数、状态与提示
pages / source_tables逐页文本、页尺寸、OCR标记；原表行列、工作表、单元格及位置
facts已识别年度指标的十进制值、原值/单位、币种、期间、口径、质量和来源
chunks / chunks_fts / embedding_cache证据片段、全文索引与可选向量缓存；不存API密钥
jobs / analysis_jobs / app_state解析任务、容器任务；app_state按项目保存conversations和runs JSON

SQLite启用WAL、外键、事务与busy timeout。原始文档、图表产物和宿主审计记录保存在受控目录，表中保存相关定位或状态；当前没有独立的事实版本表。文件按项目、SHA256及解析版本处理幂等，重启中断的解析任务明确标记失败后可重试。

交给主Agent的工具白名单用途
list_documents / get_document查看本项目文档和解析元数据
search_evidence / get_source_page / get_source_table检索片段、读取原页或指定原表
get_financial_metrics / calculate_financial_metrics查询已识别指标；进行可追踪的Decimal计算
run_analysis / get_analysis_status / get_artifact提交隔离分析、查询完成状态、获取受控产物

共10个业务工具。创建项目、上传入库、取消、凭据配置及持久化由应用宿主调用，不开放给模型。MCP返回status、data、source_refs、warnings与trace_id；project_id由宿主绑定。

03 / 从上传到结果

在对话中添加附件

在正式应用选择项目、新建对话，点击输入框旁“＋”或拖入Excel、CSV、TSV、PDF，同时写分析任务。前端先通过HTTP上传，消息携带documentIds；Agent等待该批附件解析结束后查工具，不把完整表格直接塞进上下文。

说明分析要求

例如“比较三家公司2023与2024年的营业收入，给出来源和同比，并画图”。常见年度指标可直接查事实，其他字段先检索原文或原表。缺失年份、单位和口径会在结果中明确说明；证据不足不填补猜测值。

观察当前动作

SSE展示等待解析、工具调用和流式回复。固定公式用Decimal；统计和绘图进入独立容器。可通过输入框的停止按钮取消，失败和取消有明确状态，刷新可重新读取已保存历史及工具记录。

查看结论、图表和来源

回答可包含文字、Markdown表格、可下载JSON/CSV和内嵌PNG。点击回答下方的来源按钮打开右侧原文抽屉，查看物理页、页文本与原页图像；项目资料区也可查看已解析表格。当前并未把任意数字自动绑定为可点击定位链接。

导出已有结果

顶部下载按钮导出当前对话Markdown，图表和数据文件按产物逐个下载。后端同时提供 GET /api/conversations/:id/export 返回Markdown。完整工程交付包由宿主脚本按白名单生成，页面目前没有“一键打包研究报告”功能。

文档：queued → parsing → validating → ready / needs_review / failed / cancelled 对话运行：queued → running → completed / failed / cancelled 进度阶段、工具事件、结果与错误随任务分别记录

状态与幂等由应用层和数据库承担。完整源文档保存在本机，外部模型仅接收相关工具结果；调用远程API时，这些证据片段会发送至配置的服务商。

05 / 已运行的科学计算容器

当前Windows机器通过项目内Linux VM运行真实Docker引擎，可信宿主负责提交和收集容器任务。模型不需要部署在本地；主模型使用官方API，科学计算容器只处理导出的数据与代码。

项目当前配置
预装库NumPy、pandas、SciPy、Matplotlib、Seaborn、statsmodels、scikit-learn、openpyxl和中文字体；Matplotlib使用Agg
输入输出/input只读；/output仅本任务可写；/tmp受限。不挂载原数据库、全量项目、答案目录或密钥
权限非root、只读根文件系统、cap-drop ALL、no-new-privileges、默认seccomp、network=none；容器无Docker socket
资源2 CPU、2 GiB内存、禁用额外swap、64 PID、最长120秒；输出上限50 MiB，由宿主执行限制和回收
产物校验宿主校验项目、任务、普通文件路径、符号链接、大小和SHA256；页面仅展示受控类型
复现证据依赖锁、镜像digest、实际容器配置、输入/代码哈希、退出状态、日志与产物记录保存在证据目录

容器不可用时，自由分析明确失败，不在宿主直接执行模型生成的代码。已完成真实中文绘图、资源/网络/密钥隔离、取消与恢复实验，逐项结果见最新验收记录。

本机解析层另已固定OpenCV与ONNX线程数，完整PDF并发复现保留成功、失败与修复证据，不通过吞错或跳页完成入库。容器边界面向单用户研究部署，不等于敌对多租户安全认证。

评测隔离与审计

Agent每题仅获得允许材料，使用全新项目、数据库和会话；gold、reference.sqlite、来源复核标签和原始FinQA答案不交给模型。冻结运行记录配置、实现与数据哈希；脱敏后的单题audit.jsonl保存真实工具入参及结果，正式三轮另保存重复性报告。

适用范围与限制
