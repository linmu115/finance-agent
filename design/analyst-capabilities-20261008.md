# 分析师能力层 · spec（2026-10-08）

方向：Claude；用户已确认开做 ①–⑤。实现分工：N2 负责 ④、③；N4（新会话）负责 ①、②；主线负责 ⑤；N1 负责评测对齐。开发准则见 `AGENTS.md`，优先于本 spec。

## 为什么做

技术评测的五项要求依次是：读取财报；准确取数与同比环比；解释业绩变化；识别特殊损益与口径变化；识别异常信号（尤其是利润与现金流不一致）。共同要求还包括：结构化交付、可核验可复现、区分事实/推论/观点，以及估值要写明假设、风险和适用范围。

已完成的工作主要解决了“数对不对、交付是否一致”。第 3–5 条考的是分析师的判断，金融 harness 应该在这里大幅领先通用 Agent。基本做法不变：**可确定的计算和检索由程序完成，模型负责判断、取舍和解释**。

## 共同约束
- 全部是 `financial_workpaper` 的新 kind，或现有 kind 的扩展。沿用统一契约：report 对象、A1 数值表登记、带来源的 typed cell、observations 只陈述数值关系。不新增工具名。
- 每个数值都要带来源链：文档、页码、表、行列；推导值还要列出它由哪些值推导而来。
- 依据不足就写“未知 / 无法计算”，并说明缺什么。不估算，不挪用其他期间，不把缺失写成零。
- 信号不是结论。程序给出“现象 + 阈值 + 证据”，是否构成问题由模型结合原文判断，并说明理由。
- 不针对任何评测材料硬编码行名。表名和行名的变体用规则或候选匹配处理，匹配不到的保留原文。
- **青岛啤酒是 held-out，任何会话都不得读取或用于调试。**
- 开发数据：伊利 2024（旧库副本，或重新入库后的数据）、瑞和中报、卡罗特中报、茅台 2024（samples/native-pdf），以及三份伊利券商研报（只读副本）。

## ④ 期间代数与季报（N2）
- 统一的期间推导：
  - 单季值 = 本期累计 − 上期累计，例如 Q4 = 全年 − 前三季度、Q2 = 半年 − 一季度；
  - 环比、同比、累计同比；
  - 半年报与季报的累计口径识别；
  - 比较数优先取本期报告中（可能已重述的）比较列，并标明来自哪份报告的哪一列。
- 推导值带完整来源链。两个来源期间口径不一致（例如一个重述、一个未重述）时，明确标出，不静默相减。
- 纳入季报：A 股一季报和三季报通常篇幅短、结构标准。请选一份非 held-out 公司的季报验证，例如伊利或茅台 2024 三季报，需要时先报材料与费用，确认后再入库。
- 验收：
  - 伊利 2024 年报季度表与“全年 − 前三季”的勾稽；
  - 单季推导值与季报披露值比对，有季报时；
  - 环比、同比逐项与原文或手算一致。

## ③ 口径变化探测（N2）
- 程序识别重述的原文标记：会计政策变更、会计估计变更、前期差错更正、同一控制下企业合并、“调整前/调整后”或“重述前/重述后”列、“上年同期（调整后）”等。
- 量化影响：同一指标的原报数与重述数之差，以及对关键比率（毛利率、净利率、ROE 等）的影响。原报数来自上一年报告（已入库时）或本报告的调整说明表。
- 扣非中的“准经常性”项目单独列出：持续多期的政府补助、投资收益、公允价值变动、资产处置等，以多期出现作为依据。不把它们自动改判为经常性，只提示对“扣非是否反映经营”的影响。
- 验收：
  - 至少一份含“调整前/后”比较列的真实材料（海尔 2023 可比数据有调整列；如未入库，先报材料与费用）；
  - 伊利、瑞和不应误报重述；
  - 准经常性项目在伊利非经常性损益表上的识别结果附原文核对。

## ① 异常信号雷达（N4，新 kind `anomaly_signals`）
- 程序批量计算以下信号。每项给出：计算值、对比期或对比基准、阈值与阈值来源（行业惯例或文献，写明“经验阈值”）、原文页码、数据缺失时的说明。
  1. 利润与现金流背离：CFO/净利润多期序列；应计比率，即（净利润 − CFO）/ 平均总资产；连续背离的期数。
  2. 应收：应收增速与收入增速之差；应收周转天数变化；应收账龄结构恶化（附注有账龄表时）。
  3. 存货：存货增速与成本增速之差；存货周转天数变化；跌价准备计提率变化。
  4. 其他应收款、预付款项、其他非流动资产异动：占总资产比例和增速。
  5. 存贷双高：货币资金和有息负债同时处于高位；利息收入除以平均货币资金的隐含收益率异常偏低。
  6. 季度集中：Q4 收入或利润占全年比例；Q4 与前三季的利润和 CFO 方向背离。依赖 ④ 的单季推导。
  7. 减值与商誉：资产和信用减值大幅波动；商誉占净资产比例。
  8. 非经常性损益依赖：非经常性损益占归母净利润的比例，以及多期趋势。
  9. 审计与治理：审计意见类型、强调事项段、会计师事务所变更。这几项从原文检索。
- 输出 `signals` 表：信号、数值、阈值、触发与否、证据、缺失说明。observations 只列已触发的信号。
- 工具结果给出紧凑摘要。模型要对每个触发的信号结合原文给出“可能的业务解释 / 需警惕的情形”，并区分事实与推论。
- 验收：
  - 伊利 2024 与瑞和中报全部信号可计算或已说明缺失；
  - 至少 10 个计算值与原文手算一致；
  - 在构造的合成样本上，触发和不触发都有单测；
  - 不要求“发现问题”。真实公司没有异常时，正确结果就是没有触发。

## ② 业绩变动归因（N4，新 kind `variance_attribution`）
- **利润桥**：营业收入变化 → 毛利变化，拆成收入变化效应和毛利率变化效应，拆法写明 → 各项费用 → 其他收益、投资收益、公允价值变动、减值 → 营业外 → 所得税 → 少数股东 → 归母净利润。每一步都是确定性计算，残差为零或列出。
- **结构贡献**：取分产品、分地区、分行业、分部表，计算各项对收入变化和毛利变化的贡献。披露了销量、价格、产能时，做量、价、结构拆解，并写明拆解公式。
- **原因证据对齐**：对每个主要驱动项（贡献最大的若干项），在“管理层讨论与分析”“经营情况讨论”等章节检索对应原文，附页码和原句。原文没有给出原因时，明确写“原文未说明”，原因留给模型作为推论。
- 输出 `bridge`、`contributions`、`drivers_evidence` 表，以及 observations。
- 验收：
  - 伊利 2024 利润桥残差为零或已列出；
  - 分产品贡献加总等于总变化；
  - 驱动项原文对齐至少 5 处人工核对正确；
  - 瑞和中报再跑一遍。

## ⑤ 事实/推论/观点标注与标准报告包（主线，两组共享程度见下）
- **标注**：最终回答渲染时，
  - 由 A1 绑定的数值句和带来源引用的句子自动标为“事实/数据”；
  - 其余句子由模型在写作时用轻量标记区分“推论”或“观点”，例如段首或句尾标签，具体形式由你设计，要求可读且不打断阅读；
  - 程序不替模型判定推论与观点，只校验“标为事实的句子确实有绑定或来源”，不满足时降级为推论，并在渲染中显示。
- **估值与投资判断**：出现估值结论、目标价、投资建议时，回答必须带“假设 / 风险 / 适用范围”小节；缺失时由 A1 的后续修复回路提醒一次，与占位符修复同一机制。
- **标准报告包**：一键导出“财报分析报告”：
  - Markdown 和 PDF 报告，结构为：结论 → 关键数据 → 业绩变化归因 → 特殊损益与口径 → 异常信号 → 估值（如有）→ 假设、风险与局限 → 来源；
  - Excel 底稿工作簿，分页放指标、利润桥、贡献、信号、来源清单；
  - 报告和工作簿由本次会话的数值表与底稿生成，不重新抄数。
- **公平性**：标注和报告包属于交付基建，两组都可用。底稿内容（①–④）只在金融组提供。
- 验收：
  - 单测覆盖标注降级与估值小节提醒；
  - 用一次真实会话生成报告包，检查结构、数值与数值表一致、Excel 可打开。

## 评测对齐（N1）
- rubric 和题目改为与五项要求一一对应：读取、取数与同比环比、解释变化、特殊损益与口径、异常信号；另加共同要求维度：交付结构化、可追溯、事实/推论/观点区分。
- 每题的参考答案列出该题对应的要求条目与必提要点。
- 题集补一个季报题（与 ④ 配套，材料先报审）和一个口径变化题（与 ③ 配套）。
