## 已确认

- 保留完整财报与研报入库、Pi 原生会话/压缩/重试、最低 low 清洗和既有安全权限。
- 使用独立 worktree、临时数据目录、stdio/进程内宿主；允许 CPA gpt-6-luna 真实调用与现有 Docker 沙箱。

- 改前改后使用同一瑞和 57 页 PDF；历史 DeepSeek 数字仅作背景，不能替代本轮 CPA 基线。
- 伊利完整 270 页入库留待主线合并后另行通知；本轮只做非 held-out 规模子集。

## 执行路径

1. 实际请求的系统、工具、来源表、历史及重复载荷；任务结束时的剩余进度。
2. 程序依据持久进度发送 Pi 后续消息；无推进应准确停下并交代原因。
3. 相近结构按上下文预算组批；每表独立提交合法结果。
4. 提供紧凑来源视图，保留按需完整读取；消除可证明重复的载荷。
5. 指标语义、数值列覆盖及比例/百分点/变动额提示；主体与代码跨原文证据定位。

## 不采用

不限制总工具次数，不丢表，不另造模型主循环，不要求模型逐批确认进度，不使用 held-out 材料定向修复。

## 基线运行边界

当前宿主无条件创建旧 LangExtract 的内部 HTTP 桥。测试 harness 在两组中一致禁用该未使用入口；脚本清洗工具仍由真实 RunManager、Pi、MCP stdio 和 Docker 执行。产品代码测量前保持不变。
