## 提示模板到底是什么

之前称“默认提示模板”不准确。Pi 的 prompt templates 是将 Markdown 文件转换为可复用的斜杠指令，不是一套自动附加的通用金融提示词。

官方示例在 `~/.pi/agent/prompts/review.md` 定义 `/review`，用于检查暂存的代码修改，可以传入关注点。下面是同样机制的金融示意例，**只是说明，未安装、未启用**：

```markdown
---
description: 核对财务指标口径
---
核对 $1 的期间、单位、合并或母公司口径，以及原始来源。
```

若文件名为 `check-finance.md`，则 `/check-finance 营业收入` 展开为一条普通提示。主题主要服务于 Pi 自己的界面，本应用使用自己的 Web 界面。

官方参考：[SDK](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sdk.md)、[模型目录](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/models.md)、[提示模板](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/prompt-templates.md)。本地实际集成版本为 `@earendil-works/pi-coding-agent@1.0.0`。

## 保留的边界

Pi 原生恢复不能保证上游长期断网、余额不足或认证失效时仍完成；这些错误会留下历史、任务状态和清洗检查点，而不是标为成功。任务没有工具总次数硬上限。单次沙箱资源/时限、明确配置的费用预算、逐次高权限授权和数据来源核验仍有效。

未自动重跑此前已标为 failed/cancelled 的历史任务，以免重做用户已经停止或另行处理的事项；自动恢复针对重启时尚未结束的 queued/running 任务。没有修改 Pi 依赖源码，没有另造 agent 主循环，也没有新建清洗/分析两套上下文策略。
