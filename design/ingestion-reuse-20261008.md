# 第二轮：复用优先（N3）

基线：`845991a`。本轮已由 Claude 授权实现与真实 CPA 调用，所有写入和实验限定在 N3 worktree / 临时数据目录。保持 Pi 原生运行；不操作主线文件、3001、新 HTTP 端口、Docker 生命周期及任何 held-out / N1 文件。

## 已确认范围

- 从原文确定会计准则，档案保留判定证据；模型修改必须引用支持新准则的原句。
- 程序映射标准报表行项目；不认识的行保留并交给模型。
- 规则库只存可重用映射，无文档数值、公司身份或原文；结构签名命中仍经相同校验。
- 优先核心财务表，状态显示核心覆盖；不缩减总范围。
- 单表失败不阻断其他表；禁止笼统 amount 指标掩盖实际含义。
- 伊利同一 37 页子集、茅台对应章节（不超过 40 页）验证；最后仅一次完整瑞和 57 页。费用归资料准备研发。全文伊利不执行。

## 实现决策与待验证项

1. 准则识别只采用当前文档中的明确措辞，不凭 A 股身份猜测；冲突和缺失保留未知。子集缺失原文依据时，须明确记录，不能借用测试答案。
2. 自动映射和模型映射共用 materialize / mapping_issues / commit；规则命中、通过校验、实际完成分别计量。
3. 规则版本和来源规则 ID 进入结果溯源；签名只用于查找规则，不作为正确性的证明。期间、公司和数值由当前文档重新读取。
4. 调整停滞判断的业务进度：失败表已轮转、尚有未尝试表时继续；全部剩余表均尝试且没有完成进展时准确停止。避免固定重试次数。

## 明确不采用

不增加模型逐表确认/审批，不根据样本文档 ID 写规则，不用原格回放代替财务语义验证，不把规则命中率、返回字符下降或缓存率当作费用下降。

结果、负面样例和全文 token 估计见 [第二轮结果](ingestion-reuse-results-20261008.md)。结论为部分通过：标准核心表可免模型、三份研报错误能确定性退回，伊利附注子集总输入没有显著下降，瑞和新增语义校验后仍有两张表待修复。全文伊利保持暂停。
