## 已落实

- 清洗不再登记“已读”或强制逐表填写语义复核表单，直接提交原格映射；默认返回概况、样本和具体问题，details 按需读原表与完整映射。省略人工语义结论保存为脚本标准化，不冒称全部正确。
- `run_financial_model.bindings` 使用当前项目 fact_id/record_id 和显式倍率取数，记录原值、期间、口径、来源及实际/预测身份。source_model 与 overrides 支持同类型模型局部更新，保存不可变版本；变更假设不会沿用原事实引用冒充来源披露。
- `compare_financial_models` 返回全部变化参数、数值差异和 DCF 的 FCFF 变动桥；可选顺序替换分解明确披露顺序影响。DCF 的 reference_value_per_share 给出相对敏感性区间的位置，避免把区间外值写成区间内。
- 财务质量模型增加利润至经营现金流调节。投资、融资和未归类项不计入经营调节，保留标签与未解释差额；没有披露经营现金流时差额为空，不填零。
- 研报写入支持已登记实体名称，返回可用主体；同页有效观点继续保存，失败候选及原因保留，空数组不再代表成功。确无观点使用 empty_reason；无法读取的页保留具体 needs_review 原因。
- 沙箱基础环境统一中文字体及保存边界，自动交付完整 executed_script.py；金融模式可直接读取 models.json，复用数值与标签换算、共享坐标和色标的制图助手。不在宿主执行模型代码。
- 下载类型按文件扩展名判定，CSV 不再依赖 Windows MIME 注册表；Markdown/Python 可下载，未知格式按附件下载，项目及路径权限保持不变。
- 用请求 ID 对账发送与结算，缺失结算为未知，迟到结算合并不重复计费；已完成消息与历史 run 可重新核对。记录分项计价配置，避免未来回看按另一套价格估计。
- 新增仅用于实验的 prepared 配置：通用 Pi 加只读整理数据，仍无金融模型工具、技能和金融主题。见[分账实验协议](pi-finance-analysis-protocol-20261005.md)。
