金融研究工作台 · v0.3 · 2026-10-03

围绕 Pi 会话运行的财报工作台

在会话中添加财报并发送任务，由该会话的 Agent 完成读取、语义清洗、入库、查询和制图。同项目共享资料与看板，每段会话独立运行。

LangExtract 是 process_documents 的内部实现。它需要的模型调用通过本次运行的私有桥接回所属 Pi ModelRuntime，统一使用配置、调用记录、用量和取消信号。

2. 一条带附件消息如何执行

1
添加附件
只保存原文件并登记 document_id；此时不调用模型、不写入财务事实。
2
点击发送
当前 Pi Agent 收到用户任务和附件 ID，调用 process_documents。
3
建立原文索引
PDF 独立解析进程提取逐页文字、表格和坐标；保存原文件、FTS 关键词索引与 YAML 目录。
4
模型理解并清洗
LangExtract 通过 Pi 调用 DeepSeek，结合表头、上下文解释指标、期间、单位、币种、口径、重述及分部。程序按原单元格验证数值和执行十进制换算；同一会话随后归并指标目录，并结合原文审校各事实的期间。
5
分批入库并更新看板
处理全部可提取的财务主表和附注表。每批提交后可查询，保留来源、原值、语义映射及版本。
6
继续同一次用户任务
同一 Pi Agent 接着查表、计算、调用容器制图，再回复结果与引用。切换会话不打断处理。

3. 多会话与项目共享

会话 A / Pi Session A独立上下文、工具记录与运行
例如：清洗刚上传的年报
会话 B / Pi Session B独立上下文、工具记录与运行
例如：查询已提交数据并制图
↘ 同一 project_id ↙
项目共享数据SQLite · 原始文件 · 原页原表 · YAML / FTS 索引 · 财报看板
项目之间分别绑定访问范围
其他项目独立资料、会话与看板

同会话连续提问会保留 Pi 工具上下文；刷新恢复当前状态。停止只作用于当前会话。服务重启会标明中断状态，用户可以在原会话继续处理。相同文件按项目去重，共享处理中资料时保留各自取消行为。

本阶段不调用 Embedding。Agent 可以查询实际数据库与目录位置，读取文档 YAML、全文和原表；数值检索使用结构化条件。看板分类包括利润表、资产负债表、现金流量表、财务比率、分部披露及附注。

模型工具与执行边界

工具职责
process_documents在当前 Pi 运行内读取、清洗并写入本项目；支持重新清洗。
get_data_catalog / get_document_index发现真实数据位置、字段、期间、处理状态与 YAML 导航。
query_financial_data / get_normalization_details动态指标与维度筛选；查看字段映射和数据来源。
list_documents / get_document查看当前项目资料。
search_evidence / get_source_page / get_source_table关键词检索，读取原页与原表。
get_financial_metrics / calculate_financial_metrics常用指标访问与精确计算。
run_analysis / get_analysis_status / get_artifact在独立科学计算容器执行分析与绘图，取回产物。

模型获得上述 15 个业务工具。项目由宿主绑定；宿主负责附件登记、配置和持久化。自由分析容器预装 NumPy、pandas、SciPy、Matplotlib、Seaborn、statsmodels、scikit-learn、openpyxl 和中文字体，输入只读、输出限于本任务、默认断网，使用导出的数据副本。

数据与验证入口

正式应用左侧“数据集与测试”可下载材料并运行真实模型测试。标准答案留在宿主评分阶段，不传给被测试模型。

  • 4 份无需 OCR 的完整年报：茅台 2024、伊利 2023 / 2024、海尔 2024，共 925 页。
  • 语义清洗测试集 v0.3.1：10 份输入、37 个标准事实及 2 个禁止错误检查。
  • 真实模型快速检查结果与完整年报运行记录。
  • 历史 v0.2 问答评测独立保留，不作为新版清洗成绩。

运行状态与结果以对应记录为准。小型回归集和来源抽查用于发现工程错误，不等于全部财报事实已逐条核对。

双击项目根目录 start-finance.cmd 可启动本机应用。API 配置入口位于正式应用左下角和右上角。
